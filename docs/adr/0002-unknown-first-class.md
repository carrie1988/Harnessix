# ADR 0002：将 `UNKNOWN` 作为一等结果

- 状态：已接受
- 日期：2026-09-01

## 背景

Worker 可能在外部副作用提交后、本地结果持久化前停止。二元成功/失败模型无法表达这个状态，并会诱导系统盲目重试。

## 决策

使用 `UNKNOWN` 表示外部副作用可能已经提交。`RUNNING` 租约过期不能回到 `READY`。只有 Executor 专用的对账操作才能把 `UNKNOWN` 解析为成功、确定失败或人工介入。

## 结果

- 降低非幂等副作用重复发生的概率；
- Executor 必须保留业务幂等键或外部关联信息；
- 部分 Action 会诚实停留在人工介入，而不是伪造恢复结果；
- 项目不宣称任意外部系统上的 Exactly Once。
