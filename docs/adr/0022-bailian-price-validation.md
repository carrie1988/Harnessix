# ADR 0022：百炼单次计价验收的证据边界

- 日期：2026-09-03
- 状态：验收方案已确定，真实计价验证待当次预算授权
- 范围：0.4.3c，不新增通用价格目录或改写 CostReport v1

## 1. 为什么还需要计价验收

已通过的三个真实 Smoke 验证了文本、工具与审批闭环，但白名单报告只保留场景汇总计数，不保留逐次实际模型、时间和价格绑定。不得根据请求模型名补造响应事实，也不得用 1708/208 的已知汇总消费代表包含失败请求的总账单。

现有 `bind_price`、`build_cost_report`、Session Replay 已具备实现能力。下一步是用一次受控响应串联这些已有公共接口、保存可重算的最小证据，而不是为了验收再建设一套运行时。

## 2. 已求证的地域与计价规则

用户已确认北京地域。资料核对日期为本 ADR 日期，实际执行前须再次确认快照仍适用：

- [Base URL 总览](https://help.aliyun.com/zh/model-studio/base-url)：北京按量付费使用 `https://dashscope.aliyuncs.com/compatible-mode/v1`；不能把其他地域或订阅方案凭据混用。
- [qwen-plus 模型页](https://help.aliyun.com/zh/model-studio/qwen-plus)：固定快照 `qwen-plus-2025-01-25`，非 Thinking；已核对的公开 Token 单价为输入 0.8、输出 2 元/百万 Token。实际模型必须与该快照一致，不能凭请求别名猜测。
- [预置吞吐长输入与缓存](https://help.aliyun.com/zh/model-studio/ptu-long-input-and-cache)：响应顶层 `service_tier=ptu-standard` 表示 PTU；`default` 或未返回表示按量计费。该规则是百炼专属文档语义，不是从 OpenAI SDK 默认值推断。

**决策**：只在已核对的百炼端点/固定模型范围内，由验收宿主应用这条平台规则。响应缺失等级与 OpenAI 的 `auto` 不能混为一谈；需要确认原生字段确实缺失或为 default，其他值停止自动计价。当前通用解析器会把 auto 视为不确定等级，因此只看归一化后的 None 不足以证明原生字段缺失。通用 `resolve_billing_context` 不增加“所有兼容平台都按 OpenAI 默认等级计价”的回退。

## 3. 当次调用限制

- 必须取得新的当次授权；此前 7 次请求的预算已经执行，不重复消费。
- 仅一次文本请求，无工具；输出上限 128 Token，Turn 30 秒，Token 检查阈值 2048，SDK/Adapter 零重试。
- 不读取业务工作区，不部署远程中间件；仅在私有临时目录中创建 Session。
- API Key 仅在进程内注入；禁用正文/认证日志，不保存原始 HTTP 包、异常字符串或任意模型输出。
- 认证、模型、原生等级、Usage 或价格适用性不满足时停止，不能另换地域/模型试探，也不能补默认值制造通过。

## 4. 验证顺序

1. 核对官方价目和平台规则，构造显式 `PriceSnapshot` 与宿主核对上下文：平台、北京地域、已确认的 default 等级、固定非 Thinking 模式。
2. 记录核对时间与本次允许使用的有限快照窗口；该窗口是宿主限制，不冒充供应商公布的生效承诺。过期先重新核对，不能调用后套新价格。
3. 经现有 SDK/Kernel 执行固定文本；确认只有一个尝试、完整 Usage、期望内容、合法终态与资源清理。
4. 检查原生 service_tier 缺失/default 的证据，不把 auto/PTU/其他等级折算成 default；必要的只读观察不得修改传输内容。若使用观察型真实 Transport，明确记录而不冒充无插桩执行。
5. 核对响应实际模型、尝试时间、总量与公开计数；与非 Thinking/该模型能力冲突的观测拒绝计价。
6. 调用现有价格绑定与成本报告，验证估算完整、CNY 定点金额正确、报告 JSON 重载可重算、相同 Session Replay 产生相同成本结果。
7. 保存价格快照、已核对规则来源、必要尝试事实与检查结果；真实响应 ID、Prompt、Header、任意正文不进入发布证据。
8. 失败或字段缺失如实记录 unknown/未通过；没有实际计价证据前不勾选 0.4.3c 完成。

## 5. 验收产物与明确非目标

产物复用 CostReport v1 的事实与绑定格式，配套简体中文记录说明执行代码版本、公开来源、原生字段判定和范围。增加离线证据重载与适用性负向测试，不让默认 CI 连接模型平台。

验收证明“特定平台/固定模型的一次真实用量可以按核对后的公开单价重算”。它不证明账户实际扣款、资源包/优惠/免费额度、汇率、税费或失败请求总账；不要求另建账单查询集成才能进入编码工具阶段。
