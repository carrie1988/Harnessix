# ADR 0027：先准备精确 Patch，再开放受控写入

- 日期：2026-09-03
- 状态：0.5.3a 只读准备已实现；0.5.3b 写执行与恢复尚未实现

## 1. 事实与决策

基线 `4054e1d` 四项 CI 通过。现有 EffectClass 为 read_only / idempotent_write / non_idempotent_write / destructive，并无 LOCAL_WRITE。Kernel 仍明确拒绝非只读工具，恢复也依赖该前提。不能直接删除门禁、往冻结 Action v1 增加枚举，或把文件修改伪装为只读。

本片实现宿主可调用、无工作区写入的 Patch 准备器；不向模型广告 apply_patch。下一片修改执行使用现有 NON_IDEMPOTENT_WRITE 语义及明确宿主准入，不泛化为所有写工具开放；具体意图/恢复协议通过专项测试后才启用。准备成功只表示该时刻获得一致前镜像并计算出目标内容，不表示已审批、已提交或持久保存。

专项源码证据见 [Patch 研究](../research/patch-runtime.md)。只借鉴边界，不复制实现。

## 3. 只读准备契约

`PatchProposal(path, expected_revision, edits)` 只接受工作区相对路径、现有 read_file 的 revision 和 1–32 个精确编辑。每个编辑含非空 old_text 与不同的 new_text；二者 UTF-8 合计不超过 128 KiB，所有编辑总计不超过 256 KiB。拒绝额外作用域/权限字段、模糊匹配、replace_all、空锚点、创建/删除文件及路径移动。

通过现有 Workspace FD/no-follow/对象身份机制读取整个普通单链接文件；前后镜像均最多 1 MiB，读取包含超限哨兵，不把预览或截断前缀当成完整文件。严格 UTF-8 与控制字符规则复用只读工具；拒绝特殊权限位。旧 revision 先核对，随后完整前镜像 SHA-256 由宿主计算，二者不混用。

所有编辑都定位于同一个原始前镜像，各锚点必须唯一（重叠出现也计数）；编辑区间不重叠，邻接允许，输入顺序不决定执行顺序。不做 Unicode 归一化、模糊空白匹配、换行转换、BOM 添加/去除或自动末尾换行；未涉及字节逐字保留。合法 UTF-8 锚点和替换串保持结果编码完整；替换后检查大小与实际变化。

`PreparedPatch` 保存私有 before/after bytes、提案及 manifest，正文不出现在 repr；manifest 绑定版本、工作区能力摘要、相对路径、revision、权限位、提案摘要、完整前后内容 SHA/长度及编辑数。fingerprint 对规范 manifest 计算，JSON 重开验证摘要，不是身份凭据或写授权。宿主需要保存正文/计划时必须走后续意图协议，不能仅存指纹就宣称可恢复。

`verify_prepared` 重新校验计划内部内容和当前工作区完整前镜像。根/拒绝策略、文件身份、权限、内容或 revision 变化都失败；即使新文件字节相同，替换 inode 仍是变化。该调用只复核、不写入，不自动刷新计划或重新匹配用户变化后的文件。

## 4. 写准入边界：下一片必须满足

准备 → 持久意图 → 审批完整计划 → 复核 → 提交前镜像证据 → 文件提交 → 持久结果。文件系统与 Session 不是同一个事务，不能套用 Artifact 同库原子性。提交前中断不得自动执行，提交后证据不确定不得盲目再写。

临时文件原子 rename 可以避免向读者暴露半个新文件，但**不提供“仅当目标仍是指定哈希/inode 时覆盖”的 CAS**；宿主锁也不能约束未协作编辑器。Python os.replace 支持相对目录 FD 与成功时原子替换；Linux renameat2 的 NOREPLACE 是“目标不存在”检查，而不是内容比较。[Python os.replace](https://docs.python.org/3.12/library/os.html#os.replace)、[Linux rename](https://man7.org/linux/man-pages/man2/rename.2.html)。

因此首个写执行模式须限定宿主明确管理的独占工作副本，默认不对用户正在并发编辑的源目录承诺无覆盖；受控工作副本的创建/所有权和最终 Diff 合入是后续准入条件，不能仅靠一个模型布尔字段授权。普通目录的只读准备不受此限制。未能满足独占条件时继续只读或交付计划，不偷偷降级原地写。

后续核对必须区分：仍为前镜像、吻合后镜像、第三种内容、目标丢失、元数据/目录漂移，以及因证据不完整不能确定。恢复只观察并报告，不将“当前后镜像相同”绝对归因于本次执行，不覆盖第三种用户内容。目录 fsync、临时文件生命周期、权限/xattr、磁盘满及多文件部分效果均需实际验证。

## 5. 本片验收

契约负例、唯一/重叠锚点、顺序无关、完整前后摘要、Unicode/CRLF/BOM/无末尾换行、大小哨兵、非法编码/控制字符、路径/链接/特殊文件、根/文件替换、权限和拒绝策略漂移、取消/超时与 FD 回收；默认工具定义、旧 Schema 与 Session migration 不变。独立基础 wheel 可准备/复核真实临时文件而不修改它。不使用真实模型或远程中间件。
