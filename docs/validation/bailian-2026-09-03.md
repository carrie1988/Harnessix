## 3. 根因与修复边界

当前 `ChatStream.feed` 将 `id is not None` 都视为再次声明身份，导致空字符串与首片有效 ID 比较后报漂移。结构定位与官方示例共同支持此判断，不凭错误码猜测服务不可用。

下一步只将空字符串 ID 作为无新增身份的增量占位；真实非空 ID 漂移仍拒绝，不拼接/猜测 ID，不忽略工具名漂移、不放宽 JSON/类型/终态校验。补充离线失败用例并修复后，再按用户授权范围重新进行工具与审批真实验收。
