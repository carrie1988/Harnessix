# 锁定发行物许可证据 v2

本目录保存锁定Archive的原METADATA/PKG-INFO、许可证和通知原字节；索引登记每件精确URL、SHA、大小、包名及版本。
`blobs/<sha256>`以摘要寻址，不解释归档成员为宿主路径。内容来自公开第三方发行物，相应原版权与许可声明保持不变。

正常CI运行离线报告门禁；独立核验Archive与原字节关联需显式运行采集器，不能仅凭索引声称完成重下载复核。
当前pywin32附属LGPL正文与拒绝策略冲突，12件保持发布阻断。该目录不是完整版权权属或全部分发义务证明。

设计、字段、预算、失败与复验方法见[详细设计](../../docs/changes/m09-4b-archive-license-evidence.md)。
